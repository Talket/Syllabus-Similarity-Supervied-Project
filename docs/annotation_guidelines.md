# Annotation guidelines
Compare two syllabus UNITS by the learning content they teach (not wording, not course level title).

- highly_similar: essentially the same topics; one unit could replace the other. Paraphrases count.
  Rule of thumb: >= ~70% of the topics of the smaller unit appear in the other.
- partially_similar: a meaningful shared core (roughly 25-70% of topics, or the same topic at clearly
  different depth), but each unit also has substantial content the other lacks.
- unrelated: no meaningful topic overlap. Same broad field or shared vocabulary is NOT enough
  (e.g. Linear Algebra vs Linear Programming, or two units that both mention "optimization").

Edge cases: judge the units as written; ignore course titles except for context; if torn between two
labels, pick the lower-overlap one. Also list the shared topics (empty for unrelated).
